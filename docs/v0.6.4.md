# v0.6.4 - 发布流水线重试补丁

## 日期
2026-07-07

## 变更内容

`v0.6.3` 发布时，`publish-manifest` job 的最后一步（上传合并后的 `latest.json`）遇到 GitHub API 偶发的 `HTTP 502` 瞬时错误导致失败，使该版本的 Release 缺少 `latest.json`。本版本无功能代码变更，仅为重新触发一次完整发布；同时给发布流水线中调用 GitHub API 的下载/上传步骤加上了简单的重试逻辑，降低未来再次因网络抖动导致发布失败的概率。
