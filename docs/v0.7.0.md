# v0.7.0 - 远程捏宠服务与共享生成核心

## 日期
2026-07-21

## 变更内容

本版本引入可选的内网「远程捏宠」能力：将宠物生成流水线抽成共享 crate，并新增可在 Windows 上常驻的服务端，使其他客户端无需本地配置 AI API 即可完成捏宠。客户端可在设置与捏宠面板中切换「本地 / 我的生成服务」。

---

### 1. 抽出共享核心 `aipet-core`
- 将 AI 配置、提示词、生图客户端、图像处理、布局引导、打包与完整生成流水线迁入 `crates/aipet-core`。
- 本地 Tauri App 与远程服务端共用同一套生成逻辑，避免双端实现分叉。
- 仓库改为 Cargo workspace（根 `Cargo.toml` + `Cargo.lock`）。

### 2. 内网捏宠服务端 `aipet-server`
- 新增 `server/`：Axum HTTP 服务，默认监听 `0.0.0.0:8787`。
- 支持创建任务、进度查询、基础形象确认、取消、产物下载；全局同一时刻只跑一个任务。
- 本地归档任务日志、历史摘要、预览图与 ZIP 产物；AI Key 仅保存在服务端 `ai-config.json`（已加入 `.gitignore`）。
- 提供 `config.example.json` 与 `start-server.bat` 便于内网部署。

### 3. 客户端远程创建接入
- 新增远程服务配置与远程创建命令（`remote_config` / `remote_creation`）。
- 设置页可配置生成服务地址；捏宠面板可选择本地或「我的生成服务」，并展示服务状态（空闲 / 生成中 / 等待确认等）。
- 前端类型与权限清单同步新增命令。

### 4. 工程与文档
- README 补充目录结构与远程服务快速上手说明。
- 忽略 `target/`、`server/data/`、`server/ai-config.json`，避免把密钥与运行时数据提交进仓库。
- 附带 `scripts/gen_pipeline.py` 便于流水线相关辅助脚本使用。
