# v0.7.1 - 修复 workspace 下 CI 产物路径

## 日期
2026-07-21

## 变更内容

`v0.7.0` 引入仓库级 Cargo workspace 后，编译与打包产物从 `app/src-tauri/target` 挪到了仓库根目录 `target/`。Windows / macOS 的 Tauri 构建本身已成功，但 Release 流水线仍按旧路径收集 NSIS / DMG / updater 签名，导致清单生成与资源上传失败。本版本无功能代码变更，仅修正 CI 路径并重新发布。
